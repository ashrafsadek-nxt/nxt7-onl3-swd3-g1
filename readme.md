

# Depi Angular Frontend Developer Track

## Overview
The **Depi Angular Frontend Developer Track** is a comprehensive training program designed for professional developers to master modern web development using Angular and related technologies. This program equips learners with the skills to build dynamic, responsive, and scalable web applications through hands-on courses, practical labs, and a capstone project. The curriculum covers essential front-end and back-end technologies, coding best practices, version control, containerization, and testing, ensuring participants are job-ready for modern development roles.

**Program Language**: English / Arabic  
**Total Contact Hours**: 120 (81 Online, 39 Physical)  
**Assignments**: 39 hours  
**Total Program Duration**: 159 hours

---

## Program Objectives
- Master Angular framework and its ecosystem for building robust web applications.
- Develop proficiency in front-end technologies like HTML5, CSS3, JavaScript, TypeScript, and Bootstrap.
- Gain foundational back-end skills using Node.js and Express for API development.
- Learn industry-standard practices for code style, documentation, testing, and version control.
- Understand containerization with Docker to streamline development and deployment workflows.
- Build a professional-grade portfolio through hands-on labs and a capstone project.

---

## Benefits of Enrolling
- **Enhanced Skillset**: Gain expertise in Angular and modern web development technologies, making you a competitive candidate in the job market.
- **Practical Experience**: Hands-on labs and real-world projects ensure you can apply theoretical knowledge effectively.
- **Career Growth**: Acquire in-demand skills for front-end and full-stack development roles.
- **Collaboration and Productivity**: Learn version control with Git/GitHub and best practices for team-based development.
- **Scalable Development**: Master containerization and testing to build reliable, maintainable applications.

## Course Breakdown

### 1. Prompt Engineering
**Hours**: 6 (3 Online, 3 Physical)  
**Sessions**: 1 Online, 1 Physical  
**Description**: Learn to design intelligent, context-aware prompts to enhance Angular projects with AI-driven functionalities. Master prompt engineering techniques to optimize user interactions and data flow.  
**Sessions**:
- **Session 1**: Introduction to Prompt Engineering (Concepts, Types, Best Practices, Hands-on Exercises)
- **Session 2**: Advanced Prompt Engineering Techniques (Chaining, Optimization, Ethical Considerations)

**Benefits**: Craft efficient code, improve problem-solving, and integrate AI-driven features into Angular applications.

---

### 2. HTML5 Essentials
**Hours**: 12 (9 Online, 3 Physical)  
**Sessions**: 3 Online, 1 Physical  
**Description**: Gain foundational HTML5 skills to develop web applications, focusing on programming logic, user interfaces, and accessibility.  
**Sessions**:
- **Session 1**: Introduction to HTML5 (Evolution, Semantic Tags, DOM, Cross-Browser Compatibility)
- **Session 2**: Building and Validating HTML5 Pages (Headings, Links, Images, Accessibility, Validation)
- **Session 3**: Forms and Multimedia (Form Inputs, Validation, Audio/Video Integration)
- **Session 4**: Advanced HTML5 Features (Canvas, SVG, Geolocation, Web Storage, Drag and Drop)

**Benefits**: Build structured, accessible web applications with modern HTML5 features.

---

### 3. CSS Essentials Principles of UX/UI Design
**Hours**: 12 (9 Online, 3 Physical)  
**Sessions**: 3 Online, 1 Physical  
**Description**: Learn CSS3 to style web applications and implement UX/UI design principles for responsive, accessible layouts.  
**Sessions**:
- **Session 1**: Introduction to CSS3 (Cascading, Colors, Grid, Flexbox, Selectors)
- **Session 2**: Browser Capabilities (Box Model, Positioning, Transitions, Accessibility)
- **Session 3**: Responsive Design and Frameworks (Media Queries, CSS Grid, Bootstrap, Accessibility)
- **Session 4**: Advanced CSS Techniques (Animations, Variables, Preprocessors, Performance Optimization)

**Benefits**: Design visually appealing, responsive, and accessible web interfaces.

---

### 4. JavaScript
**Hours**: 15 (9 Online, 6 Physical)  
**Sessions**: 3 Online, 2 Physical  
**Description**: Master JavaScript fundamentals to implement programming logic, manipulate the DOM, and handle events in web applications.  
**Sessions**:
- **Session 1**: Introduction to JavaScript (Variables, Arrays, Loops, Functions, DOM Basics)
- **Session 2**: Mastering JavaScript (DOM Manipulation, Event Listeners, Scope, Best Practices)

**Benefits**: Build interactive and dynamic web applications with JavaScript.

---

### 5. TypeScript
**Hours**: 6 (3 Online, 3 Physical)  
**Sessions**: 1 Online, 1 Physical  
**Description**: Learn TypeScript’s type system and advanced features to build robust, scalable Angular applications.  
**Sessions**:
- **Session 1**: Introduction to TypeScript (Setup, Syntax, Basic Types)
- **Session 2**: Advanced TypeScript Features (Functions, Classes, Generics, Modules)
- **Session 3**: TypeScript and Angular Integration (Type Safety, Decorators, Metadata)
- **Session 4**: Practical Applications and Best Practices (Error Handling, Code Quality, Hands-on Projects)

**Benefits**: Write clean, maintainable code with improved error detection and scalability.

---

### 6. Bootstrap
**Hours**: 12 (9 Online, 3 Physical)  
**Sessions**: 3 Online, 1 Physical  
**Description**: Develop responsive user interfaces using Bootstrap’s components and grid system.  
**Sessions**:
- **Session 1**: Overview of Bootstrap (Setup, Layouts, Forms, Browser Compatibility)
- **Session 2**: Getting Started with Components (Utilities, Icons, Cards, Grid System)
- **Session 3**: Advanced Bootstrap Components (Modals, Navbars, Carousels, Accessibility)
- **Session 4**: Responsive Design with Bootstrap (Grid System, Forms, Flexbox, Mobile-First Design)

**Benefits**: Create responsive, professional-grade web interfaces efficiently.

---

### 7. Angular
**Hours**: 33 (21 Online, 12 Physical)  
**Sessions**: 7 Online, 4 Physical  
**Description**: Master Angular to build dynamic, responsive web applications with advanced techniques and best practices.  
**Sessions**:
- **Session 1**: Introduction to Angular (Architecture, CLI, First Application)
- **Session 2**: Components and Data Binding (Templates, Interpolation, Lifecycle Hooks)
- **Session 3**: Directives and Dependency Injection (Built-in/Custom Directives, Providers)
- **Session 4**: Services and HTTP (Data Sharing, REST API Consumption)
- **Session 5**: Routing and Navigation (RouterModule, Route Guards, Nested Routes)
- **Session 6**: Forms (Template-Driven, Reactive, Validation)
- **Session 7**: Advanced Topics (RxJS, Angular Material, Testing, Deployment)

**Benefits**: Build scalable, maintainable Angular applications with industry-standard practices.

---

### 8. Introduction to Backend: Node.js + Express
**Hours**: 9 (6 Online, 3 Physical)  
**Sessions**: 2 Online, 1 Physical  
**Description**: Learn to build server-side applications and RESTful APIs using Node.js and Express, integrated with Angular.  
**Sessions**:
- **Session 1**: Introduction to Node.js and Express (Setup, Routing, NPM)
- **Session 2**: Working with Middleware and Advanced Routing (Custom Middleware, Error Handling)
- **Session 3**: Integrating with Databases (MongoDB, Mongoose, CRUD Operations)
- **Session 4**: Building a RESTful API (API Principles, JWT, Testing, Deployment)

**Benefits**: Develop and integrate scalable backend services with Angular applications.

---

### 9. Code Style, Patterns, and Best Practices
**Hours**: 3 (3 Online)

**Sessions**:
- **Session 1**: Angular Code Style, Design Patterns, Advanced Best Practices, Testing, and Deployment

### 10. Containerization Basics Using Docker

- **Session 1**: Introduction to Docker, Working with Images/Containers, Networking, Advanced Concepts

### 11. Functional Documentation & Unit Testing
**Hours**: 3 (3 Online)  
**Sessions**: 1 Online

**Sessions**:
- **Session 1**: Functional Documentation, Unit Testing with Jasmine/Karma, TDD, and Real-World Scenarios

**Benefits**: Produce well-documented, reliable code with robust testing practices.

---

### 12. Getting Started with Git and GitHub
**Hours**: 3 (3 Online)  
**Sessions**: 1 Online  
**Description**: Master version control with Git and GitHub for collaborative Angular development.  
**Sessions**:
- **Session 1**: Version Control, Git Commands, GitHub Features, and Angular Integration

### 13. Capstone Project
**Hours**: 3 (3 Physical)  
**Sessions**: 1 Physical  
**Description**: Apply all learned skills to build a complete Angular application, integrating front-end and back-end technologies, with proper documentation, testing, and deployment.  
**Benefits**: Showcase your skills with a professional-grade project for your portfolio.
