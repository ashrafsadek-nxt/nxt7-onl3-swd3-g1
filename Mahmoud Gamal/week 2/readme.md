## Introduction

In this week, you'll build a signup page inspired by Facebook's design using Bootstrap and HTML. This exercise will help you practice layout, forms, and responsive design.

## Learning Objectives

- Understand Bootstrap grid and form components
- Build responsive layouts with Bootstrap
- Create accessible and user-friendly forms

## Topics Covered

- Bootstrap grid system
- Bootstrap form controls
- Responsive design principles

## Assignments

- **Assignment 1:** Create a Facebook-style signup page using Bootstrap and HTML.  
     - Include fields for first name, surname, mobile/email, password, date of birth, and gender.
     - Use Bootstrap classes for layout and styling.
     - Ensure the form is responsive and visually similar to Facebook's signup form.
